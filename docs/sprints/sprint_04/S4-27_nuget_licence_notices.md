# S4-27 — Licence notices of the NuGet packages in the API image

> **Sprint:** 04, P2 stretch task S4-27 (1 point). **Issues:** #187. **Requirements / invariants:** CLAUDE §10, ARCHITECTURE D12 → C132; `TECH_DEBT_v3.md` TD-22; no invariant activated. TESTING_v55 (V173, V174) records the new CI check; no SPEC change.
> **Status:** done — pull request #305 open.
> **Scope:** find out which licences of the NuGet packages that the API image ships ask for a notice, and ship those notices with the image, the way the client image serves `3rdpartylicenses.txt`. **Not here:** notices of the operating-system packages of the base images (they carry their own, §5 P4), pinning the .NET SDK (§5 P2), the open Dependabot PRs (§5 P1).
> **Owner decisions (2026-11-13, asked before the task, all (a) as recommended):** **O-S4-90** — a committed `THIRD-PARTY-NOTICES.txt`, generated by a dependency-free Node script from the published `deps.json` and the NuGet package folder, checked in CI (also against a licence allowlist), so a NuGet update stays red until the file is regenerated. **O-S4-91** — the file ships only in the image (`/app/THIRD-PARTY-NOTICES.txt`) and the repository, no endpoint. **O-S4-92** — Swagger UI's embedded JavaScript gets a reviewed, hand-kept entry with its NOTICE and the bundle's licence comments, pinned to the package version. **O-S4-93** — packages without a licence file of their own get the standard licence text plus the `.nuspec` copyright (else authors). The task prompt said „Owner decisions: none“; these four were asked first because #187 left the way open.

## 2. Changes

| Area | Change |
|---|---|
| `scripts/check-api-notices.mjs` (new) | Without arguments: `dotnet publish --no-build` of the API into a temp folder, read its `deps.json` (or `--deps <file>`), read `.nuspec` and the root licence/notice files of each package from `NUGET_PACKAGES` or `~/.nuget/packages`, build the file and compare it with the committed one; `--write` writes it. Rules: licence expression in `STANDARD_TEXTS` (MIT, Apache-2.0) or package in `PACKAGE_TEXTS` with the same expression; compound expressions, other licences and packages without an expression fail; a package in `EMBEDDED` must have the reviewed version; entries for packages no longer shipped fail. Output: header, one block per package (licence, copyright or authors, project, the numbers of its texts, embedded code), then each distinct text once with „Applies to“ |
| `scripts/check-api-notices.test.mjs` (new) | 20 cases on `node:test`: ordering, standard text without placeholder, own licence file, notices file next to the standard text, deduplication (also across line endings), authors fallback, `PACKAGE_TEXTS`, `EMBEDDED`, each failure rule, `deps.json` and `.nuspec` reading (entities, `type="file"`), the package-folder reader, and that the repository's texts and entries load. Mutation check: without the licence-file rule two cases fail |
